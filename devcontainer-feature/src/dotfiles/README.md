# AlonsoFloo dotfiles forwarding (dotfiles)

When the host uses these dotfiles, forwards their git identity file into any dev container, so commits use it as on the host. It does not install the dotfiles in the container.

## Usage

Add it to every container you build, in your VS Code **user** settings:

```json
"dev.containers.defaultFeatures": {
  "ghcr.io/alonsofloo/dotfiles/dotfiles:1": {}
}
```

## What it does

The dotfiles keep the git identity (`[user]`) in `~/dotfiles/untracked/gitconfig`, included from `~/.gitconfig`. VS Code copies `~/.gitconfig` into the container but not that file. The dotfiles export its path as `DOTFILES_GITCONFIG` (`src/common/exports`), and the Feature:

- bind mounts only that file, `${localEnv:DOTFILES_GITCONFIG}`, to `/usr/local/share/dotfiles/gitconfig`; nothing else from `untracked/` enters the container;
- links it at `~/dotfiles/untracked/gitconfig` for the container user.

That is all. Git only reads it when the copied `~/.gitconfig` includes it, as the dotfiles one does; no system git or SSH config is changed. SSH uses the agent VS Code forwards from the host.

## Host without dotfiles

When `DOTFILES_GITCONFIG` is not set on the host, the mount falls back to `/dev/null` (Docker refuses a missing source), which git reads as an empty config. Nothing is forwarded and the container is created normally.

## Requirements

- VS Code must see `DOTFILES_GITCONFIG`: on macOS it reads your shell environment at startup; on Linux or WSL start VS Code from a shell (`code .`) if it is launched another way.
- Your SSH key loaded in the host agent: `ssh-add -l` (see the SSH agent recommendation in `untracked/bashconfig_exemple`).
- The Feature creates `~/dotfiles/untracked/` in the container, so do not combine it with VS Code `dotfiles.repository` cloning into `~/dotfiles`.

## Tests

```bash
# Host without dotfiles (default image + scenario)
devcontainer features test -p devcontainer-feature -f dotfiles --filter without_dotfiles
# Host with dotfiles, using the fixtures
DOTFILES_GITCONFIG="$PWD/devcontainer-feature/test/dotfiles/fixtures/gitconfig" \
  devcontainer features test -p devcontainer-feature -f dotfiles --skip-autogenerated --filter with_dotfiles
```
